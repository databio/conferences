# Agent instructions

## Conference update

For any task that researches or updates conference dates and deadlines, read
and follow `automation/update-conferences.md` completely.

The weekly update runs as the GitHub Actions workflow
`.github/workflows/scheduled-conference-update.yml`. Treat the repository
instructions as authoritative; the workflow prompt does not duplicate or
override the conference research, editing, branch, pull-request, review, or
publication rules.
