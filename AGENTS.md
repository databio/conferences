# Agent instructions

## Conference update

For any task that researches or updates conference dates and deadlines, read
and follow `automation/update-conferences.md` completely.

For ChatGPT Scheduled Task runs, use the connected GitHub repository to execute
the recurring automation workflow defined there. Treat the repository
instructions as authoritative; do not duplicate or override the conference
research, editing, branch, pull-request, review, or publication rules in the
scheduled-task prompt.
